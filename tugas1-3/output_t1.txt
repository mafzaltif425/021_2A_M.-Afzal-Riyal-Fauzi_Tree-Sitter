======================================================================
PEMERIKSAAN NODE BERNAMA VS NODE ANONIM PADA FUNGSI
======================================================================
Parent Node: function_definition (is_named: True)

Semua children (node.children) - mencakup node anonim:
  [0] type: def                    status: ANONIM   text: 'def'
  [1] type: identifier             status: BERNAMA  text: 'hitung_diskon' [field: name]
  [2] type: parameters             status: BERNAMA  text: '(harga, persen)' [field: parameters]
  [3] type: :                      status: ANONIM   text: ':'
  [4] type: block                  status: BERNAMA  text: 'return harga * (1 - persen / 100)' [field: body]

Hanya named_children (node.named_children) - node anonim disaring:
  [0] type: identifier             text: 'hitung_diskon'
  [1] type: parameters             text: '(harga, persen)'
  [2] type: block                  text: 'return harga * (1 - persen / 100)'

Contoh Node Anonim tersembunyi yang ditemukan:
  1. 'def'  -> keyword pendefinisian fungsi (node anonim string literal)
  2. ':'    -> titik dua pembuka blok kode
  3. '('    -> kurung buka pada daftar parameter (di dalam parameters)
  4. ')'    -> kurung tutup pada daftar parameter
  5. '*'    -> operator aritmetika perkalian
